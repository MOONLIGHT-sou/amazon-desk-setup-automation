Privacy Policy — Amazon Desk Setup

Effective date: September 14, 2026

Amazon Desk Setup is a personal content-management and automation application used by its owner to create and manage organic Pinterest content for an Amazon-focused desk-setup project.

Information accessed

When authorized by the account owner, the application may access Pinterest boards and Pins needed to select a destination board, verify access, check for duplicate publications, and create Pins. The application does not request or store a Pinterest password.

How information is used

Pinterest data is used only for the authorized account's content workflow, including board access checks, duplicate checks, and creating organic Pins when explicitly triggered by the owner. Pinterest account data is not sold or rented to unrelated third parties.

Security

Authentication credentials are intended to be stored as protected GitHub Actions secrets and are not intentionally committed to source code or printed in workflow logs.

Third-party services

The application uses Pinterest and GitHub. Amazon product links may also be generated as part of the project's affiliate-content workflow. Those services have their own policies and privacy practices.

Retention and deletion

Pinterest data is accessed only when required by authorized workflows. The owner may revoke Pinterest authorization and remove stored credentials at any time.

Children

The application is not directed to children under 13 and does not knowingly collect personal information from children.

Changes

This policy may be updated when the application's data practices materially change. The effective date will be updated when changes are made.

Contact

Questions can be raised through the Amazon Desk Setup project repository.
