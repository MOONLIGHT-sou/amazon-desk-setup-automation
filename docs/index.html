Amazon Desk Setup

Content management and Pinterest automation for a personal Amazon-focused desk-setup project.

About the application

Amazon Desk Setup is a personal application used by its owner to prepare, review and manage organic Pinterest content about desk setups, productivity spaces and related products.

The application can use Pinterest's authorized API to read the owner's boards and Pins for validation and duplicate checks and to create Pins when the owner explicitly triggers the publishing workflow.
