# Privacy Policy — Amazon Desk Setup

**Effective date:** September 12, 2026

Amazon Desk Setup is a personal content-management and automation application used by the app owner to create and manage organic Pinterest content for an Amazon-focused desk-setup project.

## 1. Information the application accesses

When authorized by the account owner, the application may access limited Pinterest account data required to operate its Pinterest integration, including:

- Pinterest boards and board identifiers needed to select the destination board.
- Pinterest Pins and Pin identifiers needed to check for duplicate publications.
- Authorization information (such as an OAuth access token) required to make authorized Pinterest API requests.

The application does not request or store the user's Pinterest password.

## 2. How information is used

Pinterest data is used only to:

- verify that the authorized Pinterest account and selected board are accessible;
- create and manage organic Pins for the authorized account when explicitly triggered by the application owner;
- check existing Pins for duplicate Amazon links before publishing; and
- maintain reliable operation and safety checks for the automation workflow.

The application is not intended to sell, rent, or provide Pinterest account data to third parties.

## 3. Data storage and security

Authentication credentials used by the automation are stored as protected GitHub Actions environment secrets and are not intentionally committed to the source-code repository or printed in workflow logs.

Repository source code may contain generated content and product metadata needed for the project, but it should not contain Pinterest access tokens, client secrets, passwords, or other authentication credentials.

## 4. Third-party services

The application uses third-party services including Pinterest and GitHub. Their handling of information is governed by their respective terms and privacy policies.

The project may also generate links to Amazon products as part of its affiliate-content workflow. Clicking an Amazon link takes the user to Amazon, where Amazon's own policies and privacy practices apply.

## 5. Data retention and deletion

Pinterest information is accessed only when required by the application's authorized workflows. The app owner may revoke the application's Pinterest authorization or remove the relevant GitHub secrets at any time.

If the app owner wants repository-generated project data removed, the corresponding repository files or records can be deleted through the project's normal GitHub administration process.

## 6. No sale of personal information

Amazon Desk Setup does not sell or rent personal information and does not use Pinterest account data for advertising to unrelated third parties.

## 7. Children's privacy

This application is not directed to children under 13 and does not knowingly collect personal information from children.

## 8. Changes to this policy

This policy may be updated when the application's data practices or Pinterest integration materially changes. The effective date at the top of this document will be updated when changes are made.
