Privacy Policy

Effective date: September 12, 2026

Amazon Desk Setup is a personal content-management and automation application used by the app owner to create and manage organic Pinterest content for an Amazon-focused desk-setup project.

1. Information the application accesses

When authorized by the account owner, the application may access limited Pinterest account data required to operate its Pinterest integration, including boards and board identifiers, Pins and Pin identifiers, and authorization information required to make authorized Pinterest API requests. The application does not request or store the user's Pinterest password.

2. How information is used

Pinterest data is used to verify access, select destinations, check for duplicate publications, create and manage organic Pins when explicitly triggered by the application owner, and maintain safety checks for the automation workflow.

3. Data storage and security

Authentication credentials used by the automation are stored as protected GitHub Actions environment secrets and are not intentionally committed to the source-code repository or printed in workflow logs. Repository source code should not contain Pinterest access tokens, client secrets, passwords, or other authentication credentials.

4. Third-party services

The application uses third-party services including Pinterest, GitHub, and Amazon affiliate links. Their handling of information is governed by their respective terms and privacy policies.

5. Data retention and deletion

Pinterest information is accessed only when required by authorized workflows. The app owner may revoke Pinterest authorization or remove relevant GitHub secrets at any time.

6. No sale of personal information

Amazon Desk Setup does not sell or rent personal information and does not use Pinterest account data for advertising to unrelated third parties.

7. Children's privacy

This application is not directed to children under 13 and does not knowingly collect personal information from children.

8. Changes

This policy may be updated when the application's data practices or Pinterest integration materially changes. The effective date will be updated when changes are made.

9. Contact

Questions can be directed through the project's public GitHub repository: Amazon Desk Setup on GitHub.
